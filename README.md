# Online Tutor Platform – Frontend

This repository contains the frontend of an Online Tutor Platform developed during my Full Stack Developer Internship at **Prinston Smart Engineers**.

The application provides a responsive user interface for students, tutors, and administrators to access and manage platform features.

## Key Features

- Responsive user interface
- Role-based dashboards for Admin, Tutor, and Student
- Tutor management and availability interface
- Student session booking interface
- User-friendly navigation and layouts

## Technology Stack

- React.js
- JavaScript
- HTML5
- CSS3

## Project Context

Developed as part of my hands-on internship experience, contributing to the frontend development of a MERN stack application.
